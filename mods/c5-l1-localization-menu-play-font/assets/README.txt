This directory contains the generated C5-L1 font asset used by the declared
menu localization capability experiment.

Source font: Fusion Pixel 12px proportional zh_hans
Source license: ../../../02_tools/fusion_pixel/OFL.txt
Generation script: ../../../scripts/merge_fonts2.py
Generation evidence: ../../../10_logs/C5-L1-localization-menu-play-font-20260814/font_coverage_rsans_report.json

The generated font is a derivative of the original game rsans.ttf plus CJK
glyph outlines. The source hashes and resulting hash are recorded in the Mod
manifest and the evidence bundle. This asset is experimental and is not a
release artifact until visual and distribution-rights review is complete.

# C5-L3 character-class dialog slice

This manifest is a controlled Phase 6 expansion from the trusted C5-L2
character-selection milestone. It changes only four exact `DISPLAY_SAFE`
static labels in the class-change and character-creation dialogs.

The dynamic class names, descriptions, class IDs, scripts, node paths, and
resource references are intentionally outside this batch. Production input
must be a fresh copy of `03_raw`; the prior C5-L2 executable is a reference
artifact only and must not be used as a build base.

# C3 ONE-RESOURCE — menu label alignment

This is a controlled structured-resource experiment. It changes exactly one
property in `Scenes/Menu.tscn`:

```text
HelpLabel.align: 1 (center) -> 2 (right)
```

No script, node name, NodePath, ExtResource, SubResource, signal, or resource
path is changed. The runtime check is a screenshot of the visible `Help Guides`
label on the main menu.

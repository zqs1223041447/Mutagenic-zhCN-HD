# 治理与 0 人工代码

目标不是“人类完全不参与产品”，而是**人类不承担代码劳动**。

AI 负责：代码、配置、测试、构建、迁移、资源处理、冲突、分支/worktree、CI 修复、交接与集成。

用户保留：产品方向、私有资产/凭据、真正主观偏好、公开发布批准。

默认自治边界：

- 普通开发失败由 AI 自愈。
- Worker 不推中央集成分支；Coordinator 集成。
- 开发基线未来可机器晋升，但必须有完整回滚与 Gate；Public Release 保持用户批准。
- AI 结论必须区分 PASS / FAIL / BLOCKED / NOT_RUN / INFERENCE。
- 历史证据不能为了“看起来干净”而改写结论。

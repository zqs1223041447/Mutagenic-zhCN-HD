# 装备、技能、怪物与终局

## 装备

- Base Type 可全局掉落；Item Level/高难内容控制高阶词缀 tier、特殊池和权重。
- Rare = 泛用数值上限 + 少量机制。
- Legendary = 规则改变 / Build Anchor；核心身份稳定、数值可随机。
- 无鉴定系统。
- 终局保留持续边际优化空间。

## Skills / Supports

保留现有 Active Skill + Support，不改成装备 socket。重点增加标签交互、行为改变、触发链和支持技能构筑多样性。

## Monster Mods

分为 numeric / behavior / archetype。每个词缀需要危险度、视觉可读性、CPU 成本、奖励预算，避免只有数值膨胀。

## Map / Atlas

Map Item → Craft → Consume → Instance → Boss/Drop → Next Map → Atlas。

Map 失败使用有限尝试/入口，损失地图与 crafting 投资，不删除玩家已装备物品。

Atlas V1 优先：地图家族、密度、材料、Legendary 类别、机制权重、目标农场。
